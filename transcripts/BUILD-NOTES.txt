Model (lib/model.ts, version radar-2, written from scratch):
- Reads the sealed snapshot (758 protocols, 40 on the watchlist, floor $50M).
- Ranks every rankable pre-token protocol: the whole watchlist plus all 158
  rankable pre-token protocols below the floor, 198 rows, no arbitrary cap.
  Rankable = no token recorded (mcap, gecko_id, symbol all null), not a
  wrapped/staked/bridged product (category, name words, exchange-name rule),
  name does not end in a version marker.
- Implied value = TVL x per-category multiple x growth multiplier (7d change
  clamped -60..+120, weight 0.5) x maturity multiplier (age with no token,
  0.6..1.0 over 1095 days, unknown age 365) x chain-breadth multiplier
  (1 + 0.02 per extra chain, up to 5). No protocol name is special-cased.
- Every row carries a 7-step farm plan derived from its category, chains, TVL
  and age (action, second action, weekly action, hold, claim, log), each step
  20..600 characters with a cost and a time.
- Live-token protocols (top 24 by market cap) are set aside, never ranked.

Dashboard (dashboard/index.html, app.css, app.js, written from scratch):
- Dark radar theme. Top-5 spotlight, category summary, full board table.
- Search; filters by category, chain, minimum TVL, minimum implied value;
  sorting by implied value, TVL, 7d growth, age, name; Pre-token / Live token
  tabs; detail panel for every protocol with the model's own inputs (the page
  recomputes each row and checks it against board.json) and its farm plan
  with a copy button; model sandbox sliders (category-multiple scale,
  growth weight) that recompute the table live.
- No network requests, no http/https strings in the dashboard source.
  Dashboard source totals 41,269 bytes (dossier text cap 65,536).
